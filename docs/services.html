A few useful answers

Before
we begin.

Can you help with my existing website?

Yes. A refresh, page cleanup, or ongoing content support can be a sensible starting point. Share the current website and what you want to improve so we can assess the fit.

Do I need a complete brief?

No. A short description of your organization, the problem, and any important timing is enough to start a conversation.

Who is this a good fit for?

Churches, nonprofits, community organizations, and local businesses that value clear design and practical support.

What determines the project cost?

The scope, number of pages, content, and support needed. Send a little context so the work can be discussed around your actual needs.
